# HANDOFF — Vettore

**Objective:** an offline plasmid editor for daily bench work without a commercial licence. Familiar
workflow and layout; biology computed by tested engines (pydna/Biopython/primer3).


**Repo:** github.com/MissingPackage/vettore (private) · **Guide:** `docs/USER-GUIDE.md` ·

## Decisions (see spec "Architecture")

- UI in English. GenBank is the save format; `.dna` is read-only
  (Biopython + sgffp for colours, primer tails and description).
- Enzymes: nonredundant commercial REBASE set generated by `src/vettore/enzymes.py`,
  cross-checked OVE vs Biopython in `frontend/src/__tests__/enzymeDatabase.test.ts`.
- Tm presets: Standard (default), NEB Q5, NEB Taq — always shown with the method.
- Cloning products are built by Vettore (so features and numbering are controlled) and
  cross-checked against pydna's own assembly.

## Gotchas

- pywebview exposes public `js_api` attributes recursively: keep native objects private
  (`_window`), otherwise the Windows UI thread hangs.
- Blueprint 3 typings lack `children` under React 18: cast container components.
- Vite 8's CSS minifier rejects Blueprint 3 CSS: `cssMinify: false`.
- pydna reads distribution metadata at import: PyInstaller needs `copy_metadata` (see
  `packaging/vettore.spec`), caught only by the packaging smoke test.
- pydna reports a fragment's 3' end on the opposite strand: compare overhangs with the
  reverse complement (`golden_gate.py`).
- Background subagents hit the account's session limit on 2026-10-19 night; this work was
  finished sequentially in the main session.
